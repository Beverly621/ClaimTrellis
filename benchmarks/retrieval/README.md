# Frozen retrieval datasets

`synthetic/` is a source-disjoint software fixture under the existing Apache-2.0 license, generated by
`python -m experiments.retrieval.fixtures NEW_DIRECTORY`. Claims/qrels are invented,
not human-confirmed. This is not a scientific or held-out accuracy benchmark.
Frozen input hashes are in its manifest. Seven hard-negative categories have one
query in each split; sample sizes are unsuitable for an adoption decision.

See [the offline lab contract](../../experiments/retrieval/README.md) for formal
human annotation, canonical work identities, source licensing, schema and evaluation.
Real-paper datasets must be independently annotated/adjudicated before use as a
formal benchmark. Do not upload private manuscripts or licensed publisher full text.
Local runs live in ignored `benchmarks/results/`.
